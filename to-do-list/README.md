# To-Do List

A simple to-do list app built with React and Vite. Add tasks to your list and keep track of what you need to do.

## Features

- Add new tasks
- Empty tasks are ignored
- Input clears after each task is added

## Tech Stack

- React
- Vite
- CSS

## Getting Started

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPO.git
cd YOUR-REPO
npm install
npm run dev
```

Then open `http://localhost:5173` in your browser.
